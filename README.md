### Layers

```
📂 lib
├──📁 components
├──📁 core
├──📁 data
├──📁 domain
├──📁 views
📂 tests
├──📁 integration
├──📁 unit
├──📁 widget
```
- **core**: routes, themes, constrants, config, extras
- **data**: repositories, services
- **domain**: entities, contracts
- **components**: shared widgets
- **views**: frontend for features
- **test**: unit, widgets, integrations
